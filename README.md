📊 Tracking Monthly Expense Leakage in a Business
An Excel-based Business Expense Analysis and Dashboard Project
This project compares budgeted and actual spending across departments and expense categories. It uses an interactive Excel dashboard to show where a business spends more than planned, and which areas need closer control.


📌 Project Overview
Businesses plan a budget for every department, but actual spending often goes above it. Small costs such as travel, office supplies and operational charges add up slowly and become expense leakage. Without a proper tracking system, management cannot see which department, category or month is causing the problem.
Tracking Monthly Expense Leakage in a Business is a beginner-friendly Excel project. It uses PivotTables, charts and slicers to turn 2,000 expense records into clear, actionable insights.


🎯 Project Objectives
Compare Budgeted Amount with Actual Spend
Identify departments that spend more than their allocated budget
Find the expense categories that contribute most to overspending
Calculate Variance and Variance % for every record
Analyse monthly and yearly spending trends
Flag over-budget expenses for early action
Recommend ways to reduce unnecessary expenses and improve budget planning

🧮 Key Calculations
1. Budget Variance
Variance = Actual Spend − Budgeted Amount
Positive variance → Overspending
Negative variance → Saving
Zero → On Budget
2. Variance Percentage
Variance % = (Variance ÷ Budgeted Amount) × 100
This allows a fair comparison between small and large budgets.
3. Budget Status
Over Budget  → Actual > Budget
Under Budget → Actual < Budget
On Budget    → Actual = Budget

🔬 Project Methodology
Data Collection – Prepared 2,000 sample expense records
Data Understanding – Studied each column and its meaning
Data Cleaning – Kept names and formats consistent, checked for missing values and duplicates, and used unique Expense IDs
Data Transformation – Added Variance, Variance % and Budget Status columns
Data Analysis – Built PivotTables to summarise by department, category, month and year
Visualization – Created column, bar and line charts
Dashboard Development – Combined KPIs, charts and slicers on one Final Dashboard
Conclusion – Identified problem areas and recommended actions
